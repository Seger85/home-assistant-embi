# Sicherheitsrichtlinie

Sicherheitskorrekturen werden für die neueste reguläre EMBi-Version bereitgestellt.

Bitte veröffentliche Sicherheitslücken, API-Schlüssel, private Serveradressen oder vollständige Diagnosedaten nicht in einem öffentlichen Issue. Nutze GitHubs private Schwachstellenmeldung, sofern für das Repository verfügbar, oder kontaktiere `Seger85` vertraulich mit einer möglichst kleinen Beschreibung zur Reproduktion.

Diagnosen redigieren Zugangsdaten und identifizierende Optionen. Prüfe dennoch jede Datei vor dem Teilen. Ein kompromittierter Emby-Schlüssel muss in Emby widerrufen und anschließend in Home Assistant ersetzt werden.

Die automatische Serverbereinigung ist bei neuen Installationen ausgeschaltet. Sie prüft Identität und Aktivität vor jedem Eintrag. Eine Serverlöschung lässt sich nur mit einem geeigneten Emby-Backup vollständig rückgängig machen. Details: [Datenschutz und Sicherheit](docs/security.md), [Bereinigung](docs/server-cleanup.md).
